## Codebase Patterns
- Git remotes: `upstream` (cua-verse official), `origin` (personal fork), `private` (private experiments)
- Work on `paper-experiments` branch, push to `private/paper-experiments`
- Use `eval "$(direnv export bash)"` before commands needing `.envrc` vars in non-interactive shells
- Use `uv sync --reinstall` if editable CUA packages fail to import
- **TinyClaw reference**: OpenClaw's memory system is the design reference for TinyClaw. Key docs live at `../openclaw/docs/` (sibling of agenthle-base under the AgentHLE folder):
  - `docs/concepts/memory.md` — Architecture overview: memory file layout, memory_search/memory_get tools, automatic pre-compaction flush, vector search config
  - `docs/experiments/research/memory.md` — Research notes: Letta/MemGPT + Hindsight-inspired retain/recall/reflect loop, proposed bank/ structure, opinion confidence
  - `docs/cli/memory.md` — CLI reference for `openclaw memory` (status/index/search)
  - `src/agents/tools/memory-tool.ts` — Source for memory_search and memory_get tool implementations
  - `src/auto-reply/reply/memory-flush.ts` — Source for pre-compaction memory flush logic (threshold calculation, prompt templates)
  - TinyClaw simplifies OpenClaw's design: plain keyword search (no embeddings), step-count-based flush (no token estimation), Python BaseTool (not TypeScript)
