### Key Failure Patterns

  a) NO CROSS-TURN MEMORY:
     only_n_most_recent_images=3 means the agent only sees 3 screenshots.
     No textual memory of failed strategies. Each 14-turn cycle it
     "discovers" the same things fresh.

  b) REASONING DEGRADATION → AUTOPILOT:
     32% of turns had no reasoning at all. When reasoning was present, it
     was copy-paste of previous turns. The model pattern-matches its own
     prior outputs rather than analyzing the current screenshot.

  c) R-KEY TRAP:
     R resets to the portal, triggering dialogue that gives the illusion
     of progress. Agent spends 5+ turns on dialogue each cycle before
     realizing it's back where it started.

  d) FLASH INPUT FOCUS:
     Arrow keys and WASD may genuinely not work without clicking the game
     area first to give it focus. Agent never systematically tested this.

  e) HALLUCINATION WITHOUT GROUNDING:
     Agent confidently claimed floor progress that screenshots disprove.
     No mechanism to verify stated beliefs against visual evidence.

### Improvement Ideas for Agent Harness

  a) MEMORY & CONTEXT MANAGEMENT (highest impact):
     A memory tool persisting across context would let the agent record
     failed strategies, breaking the repeating cycle. Directly motivates
     the tinyclaw memory system. Also, only_n_most_recent_images=3 is very
     aggressive — supplement with text-based state summaries that persist
     even as images are dropped.

  b) STUCK DETECTION & INTERVENTION:
     Multi-signal approach: compare last N screenshots (perceptual hash or
     pixel diff), track action diversity (entropy), and flag reasoning-free
     autopilot turns. When stuck is detected (identical screenshots, repeated
     actions, or no reasoning for N turns), escalate interventions:
       - Immediate: "Your last action had no visible effect."
       - After 5 turns: "WARNING: No progress for 5 turns. Try something different."
       - After 15 turns: Inject specific hints ("click the game area first for focus").
     (Would have caught the 49-turn keypress streak and the 59-turn autopilot phase.)

  c) HALLUCINATION DETECTION:
     Visual grounding check — compare agent's stated belief ("I'm on
     floor 2") against screenshot content via lightweight VLM or OCR.
     Agent confidently hallucinated floor progress that screenshots disprove.

  d) TURN BUDGET AWARENESS:
     Periodic reminders: "You have used 100/500 steps. You have not yet
     reached floor 2." Creates urgency for fundamentally different approaches.

  e) GAME-SPECIFIC KNOWLEDGE:
     For Flash/Ruffle: (1) click game area for keyboard focus first,
     (2) Ruffle may need specific interaction for keyboard capture,
     (3) some Flash games use non-standard controls.
