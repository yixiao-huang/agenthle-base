### Design Concerns

1. **[Design Soundness, Low] Path traversal substring check.** `".." in file_path` is adequate for the `.md`-only file constraint but not ideal. Recommend switching to resolved-path containment when US-OC-007 (tool registry) consolidates tool security.

2. **[Real-World Behavior, Medium] Agent writes memory only once in 50 steps.** The agent wrote game observations on turn 1 but didn't write again during the remaining 49 steps. AGENTS.md says "when you discover a working strategy → write it to memory" but the agent focuses on gameplay. This may improve with cross-session testing (session 2 would benefit from session 1's notes) but could also be enhanced with a more assertive memory write prompt.

3. **[Code Quality, Low] Legacy `memory/tools.py` still exists.** The old tools at `memory/tools.py` register the same names with `allow_overwrite=True`. This creates a fragile import-order dependency. Should be cleaned up or explicitly marked as deprecated.
