### Design Concerns
1. **`_check_done` fragility** (Implementation Progress): The injected user message dict `{role: "user", content: "..."}` doesn't have a `type` field, which broke `_check_done`. Any code iterating over `result["output"]` must handle heterogeneous item types. Consider adding `type: "message"` to the injected dict for consistency.
2. **Compaction summary survival** (Design Soundness): The ~100-char path text must survive summarization. If the LLM summarizer drops it as noise, post-compaction recall fails. Needs verification in a 200+ step run with compaction.
3. **US-OC-033 dependency** (Implementation Progress): Full end-to-end verification (agent calls `analyze_image` with a trajectory path) is blocked until US-OC-033 is implemented.

1. **Commit `_check_done` fix** — The fix for handling heterogeneous output items is critical. Without it, any computer call crashes the agent. *Impact: high. Effort: low. Rubric: Implementation Progress.*
2. **Add `type: "message"` to injected dict** — For consistency with other items in the output list, the injected `{role: "user", content: "..."}` should also have `type: "message"`. This prevents future code from breaking on the same pattern. *Impact: medium. Effort: low. Rubric: Code Quality.*
