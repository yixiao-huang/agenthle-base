### Design Concerns
1. **IDENTIFIER_PRESERVATION_INSTRUCTIONS always appended to system prompt** — OpenClaw conditionally includes this based on `identifierPolicy`. Our version always includes it. Minor deviation; no negative impact since identifiers should always be preserved in CUA summaries. *(Design Soundness)*
2. **No `reasoning: "high"` for summarization** — Intentionally dropped per plan doc. Could improve summary quality at higher cost. Consider as a future config option. *(Design Soundness)*
3. **Memory flush not triggering in 35K context window test** — `should_run_memory_flush()` requires tokens > (context_window - soft_threshold). With 35K window, flush threshold is 31K — the compaction at 81% (~28K) triggers before flush can fire. This is expected behavior with small windows but means flush is only tested at larger windows. *(Real-World Behavior)*
