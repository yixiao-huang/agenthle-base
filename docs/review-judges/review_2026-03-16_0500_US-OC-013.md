## Key Findings

### CRITICAL: `split_preserved_recent_turns` is a no-op in CUA

The function counts `role=="user"` messages to determine preserved turns. CUA transcripts have exactly 1 user message (the instruction), so with `preserve_count=3`, ALL messages are classified as "preserved". This means:

1. `pruneable` is always empty
2. The budget loop never runs
3. Compaction produces `summary="No prior history."` and `first_kept_index=0`
4. The agent restarts blind — no context carried forward

The acceptance criteria pass only trivially: compaction_count <= 2 because compaction does nothing, not because budget-aware splitting works.

### What works well

- Tool pairing repair (`repairToolUseResultPairing`) is solid — 9 tests cover all scenarios
- Budget calculation formula is correct per OpenClaw reference
- Constants and iterative chunk-drop logic match OpenClaw
- Code quality is high (lint clean, well-structured)

### Golden Reference Alignment

- **OK**: Budget calculation, iterative chunk-drop, constants, tool pairing repair
- **MISMATCH**: `splitPreservedRecentTurns` — spec doesn't match CUA's single-user-message reality
- **MISSING**: `MAX_RECENT_TURNS_PRESERVE=12` cap

### Core work (main session effort):
1. **Fix turn counting for CUA** (P1): Redefine "turn" in `split_preserved_recent_turns` as an assistant+tool pair (or just count total messages backward). In CUA, each "turn" is an assistant message optionally followed by its tool result. Preserving the last 3 such pairs gives immediate working context while making older messages pruneable for the budget loop.
2. **Add preserved-overflow fallback** (P2): When `pruneable` is empty but `preserved_tokens > available_for_kept`, treat the oldest N preserved messages as pruneable and run the summarization loop on them. This ensures compaction always produces a meaningful summary.
3. **Add CUA-pattern test** (P3): Build a message list with 1 user message followed by 20+ assistant/tool pairs. Verify that `split_preserved_recent_turns` returns a non-empty `pruneable` list and that the budget loop actually runs.
